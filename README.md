# Ejercicio Práctico - Módulo 2 (POO con Java)

Autor: Diego Suero - 2025-2470

Proyecto Maven con tres ejercicios, cada uno en su propio paquete y con su clase `Main` de prueba:

| Ejercicio | Paquete | Clases |
|-----------|---------|--------|
| 1. Sistema de Biblioteca | `com.mycompany.modulo2.biblioteca` | `Libro`, `Usuario`, `Prestamo`, `Main` |
| 2. Sistema de Vehículos | `com.mycompany.modulo2.vehiculos` | `Vehiculo`, `Main` |
| 3. Empresa de Telefonía | `com.mycompany.modulo2.telefonia` | `Cliente`, `Plan`, `Factura`, `Main` |

Todos los atributos son `private` y están documentados con JavaDoc.
